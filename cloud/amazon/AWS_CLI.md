# Instalación en Windows

La forma más sencilla es usar el instalador oficial de Windows (MSI):

- Descarga el Instalador de AWS CLI de 64 bits.

- Ejecuta el archivo .msi y sigue los pasos del asistente (Siguiente, Siguiente, Finalizar).

- Verificación: Abre una terminal (PowerShell o CMD) y escribe:

```
PowerShell
aws --version
```
Deberías ver algo como aws-cli/2.x.x Python/3.x.x....
