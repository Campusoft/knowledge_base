# SelfQueryRetriever

SelfQueryRetriever: Esta es una joya open-source dentro de LangChain. Es una herramienta que toma la consulta en lenguaje natural del usuario (ej: "Zapatos de menos de $50") y utiliza un LLM intermedio para separar la consulta semántica del filtro estructurado. Convierte el texto en un filtro JSON de metadatos para tu Base de Datos Vectorial de forma automática.


A Self-Query Retriever is an advanced retrieval mechanism in Retrieval-Augmented Generation (RAG) that automatically constructs structured queries from natural language inputs. This allows it to retrieve the most relevant information from a vector store using metadata filtering and semantic search.
