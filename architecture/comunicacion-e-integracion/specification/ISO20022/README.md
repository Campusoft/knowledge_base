# ISO 20022

Colección de material de referencia y ejemplos de mensajes ISO 20022 para integraciones financieras. Los archivos de origen y los ejemplos operativos se conservan en sus carpetas correspondientes.

## Contenido

- [Documentos de referencia](Documentos%20ISO/README.md) contiene publicaciones fuente.
- Las carpetas por operación contienen pares de solicitudes y respuestas XML de ejemplo.
- [Documento introductorio](ISO20022.docx) resume el contexto de la colección.
