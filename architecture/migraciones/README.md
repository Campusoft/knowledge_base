# Migraciones

Guías para planificar y ejecutar cambios de plataforma, tecnología o arquitectura. Cada guía debe cubrir evaluación, alternativas, riesgos, validación y operación de la transición.

## Categorías

- [Tecnologías](tecnologias/README.md): migraciones entre plataformas, frameworks y versiones.

## Principios

- Elegir el destino según soporte vigente, compatibilidad, requisitos y capacidades del equipo.
- Separar la actualización técnica de la modernización funcional o arquitectónica cuando sea posible.
- Migrar en incrementos verificables, con pruebas, observabilidad y una ruta de reversión.
- Registrar supuestos, riesgos, decisiones y criterios de aceptación.
