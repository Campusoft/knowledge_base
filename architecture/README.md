# Arquitectura

Índice del conocimiento de arquitectura. Para orientar el diseño de una solución, empieza por la [guía central](architecture.md); después consulta las categorías según las decisiones que debas tomar.

## Categorías

| Carpeta | Contenido |
|---|---|
| [fundamentos](fundamentos/README.md) | Atributos de calidad, principios, estándares, prácticas y calidad de código. |
| [estilos-y-patrones](estilos-y-patrones/README.md) | Estilos de arquitectura, patrones y material de microservicios. |
| [componentes](componentes/README.md) | Elementos reutilizables de una solución: función, ubicación, casos de uso y relaciones. |
| [comunicacion-e-integracion](comunicacion-e-integracion/README.md) | APIs, formatos, eventos, sincronización, flujos e integración entre sistemas. |
| [datos](datos/README.md) | Modelado, persistencia, consistencia y temas de arquitectura de datos. |
| [infraestructura](infraestructura/README.md) | Plataforma de ejecución, redes, servidores, nube y referencias de infraestructura. |
| [seguridad](seguridad/README.md) | Controles de seguridad, identidad, protección de aplicaciones y auditoría. |
| [operacion](operacion/README.md) | Observabilidad, salud, confiabilidad, despliegue y recuperación. |
| [migraciones](migraciones/README.md) | Guías para evaluar, planificar y ejecutar migraciones tecnológicas y de arquitectura. |
| [decisiones-y-documentacion](decisiones-y-documentacion/README.md) | ADR, diagramas, formatos y documentación de arquitectura. |
| [dominios](dominios/README.md) | Diseño de dominios, DDD y modelos reutilizables de negocio. |
| [casos-y-referencias](casos-y-referencias/README.md) | Casos, artículos, libros, herramientas y fuentes externas. |

Cada carpeta incluye un README con el alcance y el inventario de sus documentos. Añade nuevas notas a la categoría correspondiente y actualiza su README y este índice cuando agregues una categoría.
