# Componentes de arquitectura

Catálogo de componentes de infraestructura y aplicación. Cada ficha debería explicar qué es, qué problema resuelve, cuándo usarlo, dónde se ubica, alternativas, límites y relaciones con otros componentes.

## Documentos

- [Catálogo agrupado](catalogo.md): descripción breve, usos, recomendaciones y enlaces temáticos.
- [Plantilla para documentar un componente](plantilla.md).
- [API Gateway](API_Gateway.md): nota existente con más detalle.

## Grupos del catálogo

- Entrada, borde y tráfico.
- Aplicación y ejecución.
- Datos y almacenamiento.
- Comunicación e integración.
- Seguridad y configuración.
- Operación y entrega.

Usar el catálogo para orientación general. Mantener instalación, configuración de producto, detalles de bases de datos y plataformas cloud en sus carpetas temáticas, enlazándolos desde la fila correspondiente.
