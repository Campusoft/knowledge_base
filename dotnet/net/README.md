- [Datos](datos/README.md): ORM, LINQ, proveedores, transacciones y formatos.
- [Integración](integracion/README.md): gRPC, Kafka, SOAP, eventos y servicios.
- [Operación](operacion/README.md): hosting, diagnóstico, logging, contenedores y runtime.
- [Calidad y pruebas](calidad-y-pruebas/README.md): estilo, análisis estático y testing.
- [Aplicaciones cliente](aplicaciones-cliente/README.md): MAUI, UI y reportes.
- [Machine learning](machine-learning/README.md): ML.NET y procesamiento de datos.
- [Aplicaciones](aplicaciones/README.md): ejemplos y productos.
