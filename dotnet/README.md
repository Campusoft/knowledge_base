# .NET

Índice de la documentación de .NET y .NET Framework. La carpeta `net/` contiene la línea multiplataforma denominada .NET (incluido el material histórico de .NET Core); `net-framework/` conserva la documentación de .NET Framework.

## Plataformas

- [.NET](net/README.md): guías y notas sobre la plataforma actual y su ecosistema.
- [.NET Framework](net-framework/README.md): documentación de la implementación anterior.
- [Migraciones de .NET Framework a .NET](../architecture/migraciones/tecnologias/microsoft/dotnet/README.md): evaluación, levantamiento, herramientas y proceso de migración.

## Organización

Mantener separada la documentación específica de cada implementación. Las guías generales que apliquen a ambas deben enlazarse desde este índice, evitando duplicarlas.
