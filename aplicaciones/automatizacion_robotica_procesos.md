# Automatización Robótica de Procesos (RPA)

# UiPath 

UiPath ofrece una plataforma integral de RPA que incluye herramientas como UiPath Studio para diseñar flujos de trabajo, UiPath Robot para ejecutar automatizaciones, y UiPath Orchestrator para gestionar y escalar robots de software.

Otros productos clave son Document Understanding, que usa IA para extraer y procesar datos de documentos variados (facturas, contratos, PDFs), y soluciones de automatización en la nube (Automation Cloud).

La plataforma soporta integración con sistemas como SAP, Salesforce, bases de datos y aplicaciones web, manejando datos estructurados y no estructurados.
