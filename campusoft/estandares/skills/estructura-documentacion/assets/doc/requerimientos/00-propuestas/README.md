# Propuestas

Guardar aquí propuestas de alcance, estimaciones y alternativas que aún estén en discusión o pendientes de validación. Identificar autor, fecha, versión y estado de revisión. Una propuesta no constituye un requisito aprobado.

Si la propuesta se acepta, registrar los requisitos resultantes en `../01-requisitos/` y enlazarlos. Esta carpeta es opcional.
