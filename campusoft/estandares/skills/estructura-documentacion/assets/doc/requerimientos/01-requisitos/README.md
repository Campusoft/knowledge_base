# Requisitos

Registrar necesidades y comportamiento esperado con fuente, responsable, estado de validación y criterios de aceptación verificables.

Cuando el volumen lo justifique, organizar en `producto/`, `modulos/` y `plataforma/`. Mantener identificadores estables, por ejemplo `REQ-<AREA>-<NNN>-descripcion.md`, y enlazar análisis y planes relacionados.
