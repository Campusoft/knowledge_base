# Plantillas del proyecto

Guardar formatos reutilizables propios del proyecto, por ejemplo plantillas ADR, requisitos, análisis o planes. Indicar el tipo de documento, instrucciones de uso y campos obligatorios.

Para evitar variantes divergentes, enlazar las plantillas corporativas oficiales o indicar su identificador y versión. No copiar plantillas completas sin registrar su procedencia y versión.
