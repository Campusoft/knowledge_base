# Calidad

Organizar aquí la documentación de aseguramiento de calidad del sistema y las pruebas funcionales. Las pruebas pueden ejecutarse manualmente, mediante automatización o por agentes IA.

- [Escenarios](escenarios/README.md): casos de prueba, precondiciones, pasos, resultados esperados y requisitos relacionados.
- [Datos](datos/README.md): conjuntos de datos e instrucciones para prepararlos o reutilizarlos.
- [Ejecuciones](ejecuciones/README.md): resultados de las corridas, modalidad, ambiente, versión y referencias a evidencias o defectos.

Relacionar cada ejecución con sus escenarios y datos. No incluir credenciales ni datos sensibles innecesarios. Si el proyecto ya tiene una ubicación oficial para evidencias o defectos, enlazarla desde la ejecución en lugar de duplicar registros.
