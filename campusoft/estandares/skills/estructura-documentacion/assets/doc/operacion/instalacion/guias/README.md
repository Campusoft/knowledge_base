# Guías de instalación de componentes

Guardar guías específicas para instalar o configurar un componente concreto utilizado por el sistema, por ejemplo una base de datos, un servicio auxiliar o una herramienta requerida. Cada guía debe indicar componente y versión, prerrequisitos, pasos, configuración, verificaciones y fuentes de referencia.

Enlazar desde aquí cada guía disponible y mantener en `../README.md` el procedimiento general de instalación. No guardar secretos ni credenciales.
