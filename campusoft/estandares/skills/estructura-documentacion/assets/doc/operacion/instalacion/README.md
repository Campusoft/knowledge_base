# Instalación

Documentar los prerrequisitos y el procedimiento general para preparar un ambiente e instalar el sistema por primera vez. Incluir orden de pasos, configuración requerida, migraciones y verificaciones de resultado.

Las guías para instalar un componente específico se organizan en [`guias/`](guias/README.md) y deben enlazarse desde este índice. La publicación de una versión nueva en un ambiente ya preparado corresponde a `../despliegue/`.
