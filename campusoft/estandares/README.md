# Estándares Campusoft

Los estándares concretan criterios técnicos o de proceso que los proyectos deben seguir. Deben indicar estado, alcance, propietario, aprobador, fecha de vigencia/revisión y relación con políticas aplicables.

## Estándares

- [Estándares CI/CD](ci-cd/ESTANDARES-CI-CD.md): estándar transversal para integración, entrega y despliegue de software. La copia conserva el estado de propuesta para revisión y aprobación.

Las instrucciones para aplicar el estándar por stack y plataforma se encuentran en [Guías CI/CD](../guias/ci-cd/README.md).
