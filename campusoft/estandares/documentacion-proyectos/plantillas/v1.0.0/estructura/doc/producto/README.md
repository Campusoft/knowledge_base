# Producto

Documentar el producto desde la perspectiva del negocio, sus usuarios y las partes interesadas.

## Contenido esperado

- propósito, objetivos y alcance del producto;
- actores, perfiles y partes interesadas;
- procesos o contexto funcional;
- restricciones y supuestos de negocio;
- glosario propio del producto.

Los requisitos verificables van en `../requerimientos/`; enlazarlos desde aquí cuando ayude a explicar el alcance. Indicar fuente, responsable y estado de validación de la información relevante.
