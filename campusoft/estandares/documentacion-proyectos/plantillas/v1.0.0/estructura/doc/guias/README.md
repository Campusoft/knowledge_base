# Guías

Índice de guías prácticas propias del proyecto. Cada guía debe indicar audiencia, objetivo, alcance y versión o contexto del sistema al que aplica.

Usar las áreas especializadas cuando correspondan: las instrucciones de instalación de componentes van en `../operacion/instalacion/guias/`; build, convenciones, despliegue y soporte se documentan en sus áreas correspondientes. Esta versión no se divide en guías de usuario o guías de desarrollo.
