# Arquitectura

Describir la estructura técnica del sistema, sus límites, componentes, relaciones y decisiones arquitectónicas. Mantener las vistas suficientemente actualizadas para apoyar desarrollo, revisión y operación.

- [Vistas](vistas/README.md): contexto, componentes, flujos y diagramas.
- [Decisiones](decisiones/README.md): registros ADR.
Crear subdivisiones como backend, frontend o componentes solo cuando representen partes reales de la arquitectura y ayuden a encontrar la información. Si se requiere conservar documentos reemplazados, crear aquí una subcarpeta `historicos/`.
