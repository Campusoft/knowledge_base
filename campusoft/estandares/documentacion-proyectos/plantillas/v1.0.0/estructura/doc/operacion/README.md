# Operación

Índice de la documentación para preparar, ejecutar y mantener el sistema en sus ambientes.

- [Infraestructura](infraestructura/README.md): recursos y servicios donde funciona el sistema.
- [Instalación](instalacion/README.md): preparación inicial e instalación del sistema.
- [Despliegue](despliegue/README.md): publicación de versiones y cambios.
- [Soporte](soporte/README.md): operación rutinaria, incidentes y escalamiento.
- [Observabilidad](observabilidad/README.md): registros, métricas, alertas y diagnóstico.

La instalación inicial, las guías de instalación de componentes y el despliegue son temas relacionados, pero tienen índices separados para que sus procedimientos sean fáciles de localizar.
