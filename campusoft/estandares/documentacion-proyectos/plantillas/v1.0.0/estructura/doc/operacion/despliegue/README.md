# Despliegue

Documentar cómo publicar una versión o cambio en un ambiente preparado. Incluir artefactos de entrada, secuencia, autorizaciones, configuración por ambiente, migraciones relevantes, verificaciones posteriores y pasos de recuperación o reversión.

La generación del artefacto se describe en `../../desarrollo/build/`; la preparación inicial del ambiente se describe en `../instalacion/`.
