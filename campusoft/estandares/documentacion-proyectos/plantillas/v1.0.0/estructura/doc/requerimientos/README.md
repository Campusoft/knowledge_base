# Requerimientos

Organizar la evolución de las necesidades del sistema por etapa documental. Mantener enlaces entre requisitos, análisis, planes y estado implementado. Una carpeta o documento no implica por sí mismo aprobación ni compromiso de implementación.

## Etapas

- [`00-propuestas/`](00-propuestas/README.md): alternativas, alcance y estimaciones en discusión; opcional.
- [`01-requisitos/`](01-requisitos/README.md): comportamiento esperado y criterios de aceptación.
- [`02-analisis/`](02-analisis/README.md): análisis del problema, estado actual y alternativas.
- [`03-planes-implementacion/`](03-planes-implementacion/README.md): secuencia de implementación y verificación.
- [`04-estado-sistema/`](04-estado-sistema/README.md): capacidades existentes.
- [`90-insumos/`](90-insumos/README.md): material pendiente de análisis o validación.
Subdividir por `modulos/` o `plataforma/` cuando facilite la búsqueda; aplicar criterios coherentes entre etapas. Si un área necesita conservar documentos reemplazados, crear dentro de ella `historicos/`. Esta subcarpeta no forma parte fija de la estructura. Recomendación de identificadores: `REQ`, `ANA`, `PLAN` y `EST`.
