# Plantillas documentales v1.0.0

Esta carpeta concentra los formatos documentales reutilizables de Campusoft. Al adoptarlos en un proyecto, copiarlos juntos a `doc/plantillas/`; conservar allí un índice y registrar la versión utilizada. Los formatos se mantienen en una sola ubicación corporativa para facilitar su mantenimiento.

## Inventario

| Formato | Archivo | Uso principal |
|---|---|---|
| ADR | [ADR_plantilla.decisiones.arquitectura.v.1.0.md](ADR_plantilla.decisiones.arquitectura.v.1.0.md) | Registrar decisiones de arquitectura, alternativas, impactos y riesgos. |
| PLAN | [PLAN_plantilla.implementacion.v.1.0.md](PLAN_plantilla.implementacion.v.1.0.md) | Planificar implementación, dependencias, pruebas, tareas y criterios de aceptación. |
| POC | [POC_plantilla.pruebas.concepto.v.1.0.md](POC_plantilla.pruebas.concepto.v.1.0.md) | Definir hipótesis, criterios de éxito y ejecución de una prueba de concepto. |
| QA | [QA_plantilla.bug.v.1.0.md](QA_plantilla.bug.v.1.0.md) | Registrar un defecto, pasos de reproducción, entorno, evidencia y severidad. |
| SRS | [SRS_plantilla.requerimientos.v.1.0.md](SRS_plantilla.requerimientos.v.1.0.md) | Especificar un requisito funcional o no funcional y sus criterios de aceptación. |
| TAR | [TAR_plantilla.tarea.agente.v.1.0.md](TAR_plantilla.tarea.agente.v.1.0.md) | Encargar y registrar una tarea delegada a un agente; uso opcional según el proyecto. |
