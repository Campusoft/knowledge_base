# Node Frameworks

## NestJS

NestJS es un framework progresivo para crear aplicaciones de servidor con Node.js. Su estructura modular, la inyección de dependencias y el uso de TypeScript ayudan a mantener sistemas de backend organizados a medida que crecen. Puede servir APIs HTTP y también trabajar con GraphQL, WebSockets y microservicios. Nest usa Express por defecto y permite elegir Fastify como adaptador HTTP.

Consulta la guía ampliada de [NestJS](nestjs.md), que cubre características, arquitectura, casos de uso y recomendaciones.

## Fastify

Fastify es un framework HTTP para Node.js que destaca por su sistema de plugins, hooks y validación basada en esquemas. Puede utilizarse directamente o como adaptador HTTP de NestJS. Evalúe el ecosistema de plugins y mida el rendimiento con la carga real de la aplicación.

Sitio oficial: [fastify.io](https://www.fastify.io/).

## Actionhero

Actionhero es un framework para servidores Node.js que permite exponer acciones mediante distintos transportes, como HTTP, WebSockets y TCP. Su modelo separa las acciones de la conexión que las invoca.

Sitio oficial: [actionherojs.com](https://www.actionherojs.com/).
