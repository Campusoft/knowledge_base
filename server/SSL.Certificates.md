# Let's Encrypt


Let's Encrypt es la Autoridad Certificadora (CA) sin fines de lucro que emite los certificados TLS/SSL gratuitos. Es el proyecto que realmente proporciona los certificados que Certbot (u otros clientes ACME) solicitan.


# Certbot


Certbot funciona como un cliente ACME (Automated Certificate Management Environment), el protocolo estándar que usa Let's Encrypt (y otras CAs compatibles) para automatizar la obtención, instalación y renovación de certificados TLS/SSL.
